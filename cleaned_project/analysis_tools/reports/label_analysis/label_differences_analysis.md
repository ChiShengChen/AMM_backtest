# 策略Label定義和Rebalancing標準差異分析

## 🎯 核心發現

QASA Benchmark與其他策略在label定義和rebalancing標準上存在顯著差異：

### 1. Label類型差異
- **QASA**: 價格變化預測 (回歸問題)
- **其他策略**: 再平衡分類 (分類問題)

### 2. 預測目標差異
- **QASA**: 預測連續的價格變化率
- **其他策略**: 預測二分類的再平衡決策

### 3. 閾值設定差異
- **QASA**: 1% 價格變化閾值
- **AMM Quantum**: 30% 預測閾值
- **PennyLane**: 10% 價格變化 + 60% 概率閾值
- **Steer Intent**: 動態閾值 (基於波動率)
- **AMM Baseline**: 2% 價格偏差閾值

## 📊 詳細比較

### QASA Benchmark

- **Label類型**: 價格變化預測
- **Label定義**: 預測下一個時間步的價格變化百分比
- **Label公式**: `y = (next_price - current_price) / current_price`
- **再平衡標準**: 預測的價格變化絕對值 > 1%
- **閾值**: 0.01 (1%)
- **預測目標**: 連續值 (價格變化率)
- **模型輸出**: 回歸預測
- **決策邏輯**: `abs(prediction) > threshold`
- **模型類型**: 量子-經典混合神經網絡

### AMM Quantum Strategy

- **Label類型**: 再平衡分類
- **Label定義**: 基於價格偏差的分類標籤
- **Label公式**: `y = 1 if price_deviation > threshold else 0`
- **再平衡標準**: 量子模型預測 > 閾值
- **閾值**: 0.3 (30%)
- **預測目標**: 二分類 (是否再平衡)
- **模型輸出**: 分類預測
- **決策邏輯**: `prediction > rebalance_threshold`
- **模型類型**: 量子神經網絡

### PennyLane Quantum

- **Label類型**: 價格變化分類
- **Label定義**: 基於價格變化幅度的分類標籤
- **Label公式**: `y = 1 if abs(price_change) > threshold else 0`
- **再平衡標準**: 量子預測 = 1 且 概率 > 0.6
- **閾值**: 0.1 (10%)
- **預測目標**: 二分類 (是否再平衡)
- **模型輸出**: 分類預測 + 概率
- **決策邏輯**: `prediction == 1 and probability > 0.6`
- **模型類型**: PennyLane量子分類器

### Steer Intent Classic

- **Label類型**: 位置管理
- **Label定義**: 基於布林帶位置的分類標籤
- **Label公式**: `y = 1 if |BB_position - 0.5| > 0.3 else 0`
- **再平衡標準**: 多個觸發條件 (間隙、漂移、時間)
- **閾值**: 動態 (基於波動率)
- **預測目標**: 二分類 (是否調整位置)
- **模型輸出**: 觸發器組合
- **決策邏輯**: `多個觸發器OR邏輯`
- **模型類型**: 規則基礎策略

### AMM Baseline

- **Label類型**: 價格偏差
- **Label定義**: 基於價格與移動平均線的偏差
- **Label公式**: `y = 1 if |price/MA - 1| > threshold else 0`
- **再平衡標準**: 價格偏差 > 2%
- **閾值**: 0.02 (2%)
- **預測目標**: 二分類 (是否再平衡)
- **模型輸出**: 簡單規則
- **決策邏輯**: `price_deviation > threshold`
- **模型類型**: 規則基礎策略

## 🔍 關鍵差異分析

### QASA的特殊性
1. **回歸vs分類**: QASA是唯一使用回歸預測的策略
2. **連續預測**: 預測連續的價格變化而非離散的再平衡決策
3. **低閾值**: 1%的閾值比其他策略更敏感
4. **混合架構**: 量子-經典混合神經網絡

### 其他策略的共同點
1. **分類問題**: 都是二分類的再平衡決策
2. **規則基礎**: 大部分基於技術指標的規則
3. **較高閾值**: 2%-30%的閾值範圍
4. **特徵工程**: 基於技術指標的特徵

## 💡 影響分析

### 對比較結果的影響
1. **不公平比較**: 不同的label定義導致比較不公平
2. **閾值敏感性**: QASA的低閾值可能導致過度交易
3. **模型複雜度**: 回歸問題比分類問題更複雜
4. **特徵需求**: 不同策略需要不同的特徵工程

### 建議改進
1. **統一label定義**: 所有策略使用相同的label標準
2. **標準化閾值**: 使用相同的閾值進行比較
3. **公平比較**: 確保所有策略解決相同的問題
4. **特徵一致性**: 使用相同的特徵工程方法
